# Fonts

`archivo-rank-digits.woff2` draws the numerals of the numbered row ("Top rated you haven't seen").
It is **Archivo** by Omnibus-Type (https://github.com/Omnibus-Type/Archivo), version 2.001, from the
Google Fonts repository, pinned to a static instance (width 62, weight 900) and cut down to the
digits 0–9 (about 1.5 KB). `../../scripts/mkfont.py` rebuilds it.

Archivo is licensed under the SIL Open Font License 1.1: see `OFL.txt` in this folder. The font
declares no Reserved Font Name.

Inter, the typeface for all text, comes from the `@fontsource-variable/inter` package (also OFL).
